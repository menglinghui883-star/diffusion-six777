# Diffusion Six — Denoising Digit '6'

A small demo project showing the full MLOps lifecycle:
train a denoising model → package it with Docker → test it with pytest → deploy it as a web app.

The task: take a noisy 8×8 image of the handwritten digit "6" and reconstruct the clean image using a small CNN, compared against a linear regression baseline.

---

## Project Structure

```
diffusion-six/
├── train.py                  # Train linear baseline + CNN, save model.pt
├── app.py                    # Streamlit web app
├── model.pt                  # Trained CNN weights (generated by train.py)
├── requirements.txt          # Python dependencies
├── Dockerfile                # Docker packaging
├── README.md
├── .gitignore
├── tests/
│   └── test_diffusion.py     # pytest test suite
└── .github/
    └── workflows/
        └── test.yml          # GitHub Actions: auto-run tests on push
```

## How to Run Locally

### 1. Install dependencies

```bash
python -m venv venv
source venv/bin/activate    # On Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Train the model (if you don't have model.pt yet)

```bash
python train.py
```

This will:
- Load digit "6" images from scikit-learn's digits dataset
- Train a linear regression baseline
- Train a small CNN denoiser
- Save the trained CNN as `model.pt`
- Print a MSE comparison and save `comparison.png`

### 3. Run the Streamlit app

```bash
streamlit run app.py
```

Then open http://localhost:8501 in your browser.

---

## How to Run Tests

```bash
pytest tests/ -v
```

The tests check:
- Image dimensions are correct (8×8)
- Adding noise returns an 8×8 image with finite values
- The CNN produces output of the right shape and range
- The saved model weights load correctly

---

## How to Build and Run with Docker

### Build the image

```bash
docker build -t diffusion-six .
```

### Run the container

```bash
docker run -p 8501:8501 diffusion-six
```

Then open http://localhost:8501.
